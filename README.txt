SHIFTLEDGER v3.0 PWA package
1. Upload index.html, manifest.webmanifest, sw.js and icon.svg to the root of your GitHub Pages repository, replacing the old files.
2. Keep the repository on main / root and GitHub Pages enabled.
3. Open the Pages website in Chrome, refresh, then install/add to Home screen.
4. Before updating, use the app's Backup button. This release keeps the existing localStorage key (shiftledger_punch_v2) so same-origin records are retained.
5. Data remains local to the browser/device. Keep regular JSON backups.
